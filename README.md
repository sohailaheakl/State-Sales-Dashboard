# 🏠 Real Estate Sales Dashboard | Power BI

A Power BI project focused on **data modeling** and building an interactive dashboard to analyze real estate sales performance.

## 📊 Key Metrics (DAX Measures)
- Number of Houses
- Quantity Sold
- Total Sales (Selling)
- Total Cost
- Total Profit

## 📈 Visuals
- **KPI Cards** – headline metrics at a glance
- **Line Chart** – sales & profit trend by month
- **Pie Chart + Treemap** – sales distribution by location
- **Donut Chart** – profit share by property type
- **Column Chart** – sales performance by salesperson
- **Matrix** – quantity sold by location & property type
- **Slicers** – filter by location and sale date

## 🧱 Data Model
- `Data` table: SaleDate, Location, PropertyType, SalesPerson
- `Measures` table: all calculated DAX measures

## 🛠 Tools
Power BI Desktop · DAX · Data Modeling

## 🚀 How to Use
1. Download `data_modelling_project.pbix`
2. Open it with [Power BI Desktop](https://powerbi.microsoft.com/desktop/)
3. Use the slicers to explore the data
